# 🙏 Japa

A modern Android application built using Kotlin and Jetpack Compose to help users perform Japa (Mantra Chanting).

---

## Features

- Add custom mantras
- Set chanting goals
- Home screen with saved mantras
- Manual counting
- Progress tracking
- MVVM Architecture
- Jetpack Compose UI
- Navigation Component

---

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Navigation Compose
- Material 3
- Android Studio
- Git & GitHub
